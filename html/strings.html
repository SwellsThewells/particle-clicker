Tiny vibrating strings

In string theory, the elementary particles are not points but tiny strings, far too small for any experiment to see. A string can vibrate in different ways, like a violin string playing different notes, and each way of vibrating looks like a different particle.

One of the vibrations behaves exactly like the graviton, the particle that would carry gravity. That is why string theory is a candidate for a theory of everything: it describes gravity and quantum physics together.

A landscape of universes

String theory only works with extra dimensions of space, curled up into complicated shapes called Calabi–Yau manifolds. There are enormously many ways to curl them up, by some estimates 10500, and each gives a universe with its own particles and forces. Some physicists think that all of them could exist, as a multiverse.

String theory has also given physicists new tools, such as the AdS/CFT correspondence, which describes a universe with gravity using a theory without it. No experiment has tested string theory directly yet.
